## Install in Kodi

### 1. Allow installation from ZIP files
1. Go to **Settings → System → Add-ons**.
2. Enable **Unknown sources**.

### 2. Add the OpenXStream source
1. Go to **Settings → File Manager**.
2. Select **Add source**.
3. Enter:
   ```text
   https://openxstream.github.io/repository.OpenXStream/
   ```
### 3. Install the repository
1. Open **Add-ons**.
2. Select **Install from ZIP file**.
3. Select the source you created and install the repository

### 4. Install add-ons
1. Select **Install from repository**.
2. Select **OpenXStream Repository**.
3. Browse the available add-ons.

## Updates

Once the OpenXStream Repository is installed, Kodi can automatically check for available add-on updates.
